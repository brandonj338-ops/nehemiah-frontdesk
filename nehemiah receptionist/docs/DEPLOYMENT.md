# Deployment Guide (Render — free, no coding)

This gets your AI front desk live on the internet so your AI agent / website widget can call it.
Demo mode needs **no credentials**, so you can deploy first and add real keys later.

## Part 1 — Put the code on GitHub (5 min)

1. Make a free account at https://github.com
2. Click **New repository** → name it `nehemiah-frontdesk` → **Create**.
3. On the new repo page, click **uploading an existing file**.
4. Drag in the whole `nehemiah-frontdesk` folder contents (everything except `node_modules`).
5. Click **Commit changes**.

## Part 2 — Deploy on Render (5 min)

1. Make a free account at https://render.com (sign in with GitHub).
2. Click **New +** → **Web Service**.
3. Pick your `nehemiah-frontdesk` repo.
4. Render reads `render.yaml` automatically. Confirm:
   - Build command: `npm install`
   - Start command: `npm start`
   - Plan: **Free**
5. Click **Create Web Service**. Wait ~2 minutes for "Live".
6. Copy your URL, e.g. `https://nehemiah-frontdesk.onrender.com`.
7. Test it: open `https://YOUR-URL/health` — you should see `{"ok":true,...}`.

**Your `API_KEY` is auto-generated by Render.** Find it under your service → **Environment**.
Your AI agent must send it as header `x-api-key`.

## Part 3 — Go live (when ready)

Switch off demo mode and add real credentials in Render → **Environment**:

1. Set `DEMO_MODE` to `false`.
2. Add Google keys — see **docs/GOOGLE_SETUP.md**.
3. Add Twilio keys (`TWILIO_SID`, `TWILIO_AUTH`, `TWILIO_NUMBER`).
4. Add email (`SMTP_USER`, `SMTP_PASS` — for Gmail use an App Password).
5. Set `GOOGLE_CALENDAR_ID` to **Tre's calendar** for the demo; swap to Nehemiah's later.
6. Click **Save, rebuild and deploy**.

> Free Render services sleep after 15 min idle and take ~30s to wake. Fine for a demo.
> For always-on, upgrade to the $7/mo plan later.

## Connecting the AI agent / website widget

Point your agent's tool/webhook at:
`https://YOUR-URL/api/webhook/claude` (send header `x-api-key: YOUR_KEY`)

Body shape: `{ "action": "intake", "payload": { ... } }` — see **docs/API.md**.
